# physics-classroom-115
八年級理化互動實驗室：17 個繁體中文互動實驗（波動聲音依講義 3-1～3-4、光學依翰林第四章「光、影像與顏色」4-1～4-5、溫度與熱 5-1～5-2 編排），支援課堂投影與離線使用。

4-4 透鏡成像包含：為什麼會偏折（一疊三稜鏡）、焦點與焦距、成像（成像規律表＋例題）、光具座實驗、為什麼會模糊（透鏡＝很多個小孔，像錯開疊在一起）；生活中的透鏡包含照相機、投影機、放大鏡、顯微鏡、眼睛與近視／遠視。

5-1 溫度與溫度計包含：用手感覺可靠嗎、溫度計的種類（液體、體溫計縮口、雙金屬片、電子、紅外線）、液體溫度計的設計（泡大管細較靈敏）、溫標的制定（兩定點等分，含自訂溫標）、溫標的換算（°C、°F、自訂 X，K 為補充）。5-2 熱量與熱平衡包含：卡與千卡、H ＝ m × ΔT（只算水，尚未教比熱）、冷熱水熱平衡（可打開散熱比較）。

入口為 index.html；offline.html 可下載後離線開啟。

img/ 放各實驗右側的實物示意圖（WebP，AI 生成）；離線版會把它們內嵌進同一個 HTML。

修改 index.html、style.css、app.js 或 img/ 後，執行 `node build-offline.js` 重新產生 offline.html。
